# Documentation

All project guides live in this wiki/ directory alongside the src/ and utils/ directories in the repository.

| Guide | What it covers |
| --- | --- |
| [Configuration](configuration.md) | Module metadata, local Foundry configuration, build settings, and project conventions |
| [Development](development.md) | Source and output layout, development builds, linking, the local launcher, and compendiums |
| [Runtime](runtime.md) | Lifecycle, settings, public API, optional wrappers, and Foundry smoke tests |
| [Releasing](releasing.md) | Changelog preparation, exact-tag artifacts, release descriptions, and installation |
| [Upstream](upstream.md) | Reviewed DFreds sources, deliberate differences, and explicit upstream comparisons |

Start with the [project README](../README.md) for setup and the command overview. The [utility reference](../utils/README.md) documents developer commands implemented in utils/.

The documentation directory is copied into built modules. Developer utilities remain repository tools and are excluded from the installed package.
